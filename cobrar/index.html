Como vai ficar

Esta é a sua página de pagamento de verdade, carregada do seu site com o link que você acabou de gerar. Não é um desenho parecido: é a página, com o código que está colado lá.

O quadro é só para olhar — o toque não passa por ele, para você não pagar sem querer a sua própria cobrança. Role dentro dele para ver a página inteira; para mexer de verdade, abra em outra aba.

Se aparecer uma recusa aqui, é o aviso que você precisava: quer dizer que o código colado na sua página de pagamento é anterior a esta cobrança e não entende algum parâmetro dela. Gere de novo o Código 1 na ferramenta completa e recole no site — depois disso a prévia mostra o cartão normalmente.

Esta é a única parte desta página que precisa de internet. O link em si é montado no próprio aparelho, e continua sendo mesmo sem conexão.
